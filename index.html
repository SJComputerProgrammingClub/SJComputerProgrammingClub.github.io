Joining

Two steps.

Membership starts at school. Once you are a member of the club, getting into the GitHub organization is one issue.

  1. 01

    Open the signup repository

    github.com/SJComputerProgrammingClub/signup

  2. 02

    File an issue

    Filing the issue is how a member is added to the organization. The button above opens the signup page with the issue form.
